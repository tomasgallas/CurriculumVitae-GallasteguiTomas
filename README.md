# 📄 Curriculum Vitae - Tomás Gallastegui

> CV web interactivo, moderno y adaptable, diseñado con **React**, **TypeScript** y **Tailwind CSS**, optimizado para visualización digital y exportación perfecta a formato **A4 PDF**.

🔗 **Demo en vivo:** [tomasgallas.github.io/CurriculumVitae-GallasteguiTomas](https://tomasgallas.github.io/CurriculumVitae-GallasteguiTomas)

---

## ✨ Características

- 🎯 **Optimizado para A4:** Estilos de impresión `@media print` milimétricamente ajustados para exportar a PDF en una sola hoja estándar A4.
- ⚡ **Rápido y Reactivo:** Desarrollado sobre Vite y React 18.
- 🎨 **Diseño Moderno:** Estilizado con Tailwind CSS, iconos de Lucide React y componentes accesibles.
- ♿ **Estructura ATS-Friendly:** Jerarquía semántica pensada para lectores de pantalla y sistemas de seguimiento de candidatos.

---

## 🛠️ Tecnologías

- **Core:** React 18, TypeScript, Vite
- **Estilos:** Tailwind CSS
- **Iconografía:** Lucide React, MUI Icons
- **Despliegue:** GitHub Pages (`gh-pages`)

---

## 🚀 Instalación y Uso Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/tomasgallas/CurriculumVitae-GallasteguiTomas.git
   cd CurriculumVitae-GallasteguiTomas
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar entorno de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Compilar y desplegar a GitHub Pages:**
   ```bash
   npm run deploy
   ```
